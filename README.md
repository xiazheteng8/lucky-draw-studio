## 🎯 多种抽奖方式，一个活动工作台

| 参与方式 | 使用场景 | 功能说明 |
| --- | --- | --- |
| 📺 YouTube 视频评论 | 视频福利、频道互动 | 导入视频评论，筛选符合条件的参与者后抽奖 |
| 📝 Blog 评论 | 博客活动、文章互动 | 从支持的文章评论来源导入；不同站点兼容性不同，导入后可检查名单 |

评论模式支持关键词、时间范围、参与者去重、排除视频作者，以及频道 ID 黑白名单等筛选。**开奖前可先检查实际参与名单与人数。**

创建活动时可设置主办方、活动名称、中奖人数、手动逐位或自动连续开奖、定时开奖、虚晃次数及最终公示文案。主办方名称会显示在各主题大屏的主标题位置。

### 🖼️ 你的活动，你来设计

- **活动 LOGO**：上传主办方或活动标识。
- **奖项与奖品**：自定义获奖名称、各名次奖品名称及图片；上传图片优先展示。
- **文件夹上传奖品**：`1.png` 或 `1.jpg` 对应第一名，`2.png` 对应第二名，以此类推。
- **默认奖章与领奖台**：未上传图片时使用对应的默认奖章；开奖结束展示获奖头像与颁奖效果。
- **按活动保存**：活动管理里的奖品、音乐设置作用于对应活动，新建页的设置用于新活动。
- **音乐试听**：候场、摇奖、颁奖分别选择曲库或上传音频，支持试听、音量与中奖音效开关。
- **独立音乐**：本场音乐只影响当前活动，各主题默认音乐由站长在后台维护。

## 📺 候场、揭晓、颁奖，大屏全程展示

**候场 → 抽奖 → 虚晃 / 中奖揭晓 → 烟花彩带 → 领奖台。**

大屏可浏览器全屏，也可作为 OBS 浏览器来源。全屏按可用空间适配布局，保持模块与头像比例。

- 扫码活动展示小程序码、签到、祝福留言和爱心互动。
- 视频、Blog 或不开放报名的名单活动，展示活动概况、奖品、头像及等待开奖信息。
- 头像粒子近大远小，候场与抽奖资源提前准备，减少切换时的等待。
- 已真实中奖者排除后续候选；**同一轮仅被虚晃展示过的人，仍有机会真正中奖**。
- 每位真实中奖者都有完整庆祝过程，结束后集中公示结果。

## 📱 微信小程序互动

观众用微信扫描活动小程序码，进入对应活动。头像与昵称用于报名和大屏展示，由用户主动选择、填写，不能承诺静默读取真实资料。

| 互动 | 展示效果 |
| --- | --- |
| ✅ 签到 | 头像、昵称与签到提示进入大屏 |
| 💬 留言 | 6 个快捷祝福，85 条随机搞笑候场预填留言，也可自定义 |
| ❤️ 爱心 | 红色悬浮爱心，短时间连点合并展示数量 |
| 🌸 鲜花 | 与主题搭配的花瓣效果 |
| 🚀 火箭 | 点火、蒸汽与升空动画，支持有限数量同时出现 |
| 🏎️ 跑车 | 转动轮胎、起步烟雾、随机加速与竞速效果 |

留言每次进入输入框都会清空，发送成功后补充新的随机预填内容；纯文字自定义留言可随机加入表情。

**防刷屏由服务端执行：**默认留言每人每活动 30 秒一条；火箭、跑车默认每人每活动各一次。站长可调整开关与限额，各场活动独立计算，刷新或重新登录不会重置已用次数。礼物为免费互动效果。

## 🎬 保存这份幸运

- 🖼️ 导出结果图片，保存获奖名单。
- 📊 导出 Excel 等名单文件，便于核对和存档。
- 🎞️ 导出候场、摇奖或完整过程 MP4。
- ⏱️ 回放全过程可选择保留候场时长，默认保留全部已记录候场。
- ⚡ 支持的浏览器使用快速编码，预览显示生成过程，成片保持正常速度；不支持时使用实时兼容方式。
- 🔔 回放、音频合成、MP4 合成与保存分阶段提示。

> **回放保存的是本浏览器里的活动数据，用来重绘舞台画面，包含配置音乐；不录制麦克风或其他窗口。**从打开大屏开始计时，最小化继续、关闭停止，再打开可续接。请在同一浏览器、同一站点导出，不要提前清理网站数据。删除活动会清理本浏览器内对应的回放记录。

## 🛠️ 站长后台与账号管理

平台账号使用**用户名 + 密码**。用户可直接注册，也可填写站长生成的一次性注册码；有效注册码每个仅可使用一次。站长可审核用户为已认证用户，未认证用户按后台设置的活动与保留期限使用。

后台还可管理：

- 用户、认证状态和注册码；
- 未认证活动的有效期、保留时间与游客创建开关；
- 各主题默认音乐；
- 留言间隔和礼物限额；
- YouTube API 与第三方签到配置。

**没有通用默认账号或密码。**首次部署访问 `/setup`，使用本机初始化密钥创建站长；以后从 `/owner` 登录。普通用户入口是 `/account`。

## 🔑 API 要配置哪些？

| 你的需求 | 是否需要额外平台凭证 | 教程 |
| --- | --- | --- |
| 名单抽奖、主题、音乐、导出 | 无需第三方抽奖 API | [部署网站即可](docs/DEPLOY-VPS.md) |
| YouTube 评论 | YouTube Data API v3 Key | [YouTube 配置](docs/API-CONFIG.md#youtube) |
| 微信小程序报名 | 小程序 AppID / AppSecret、合法域名 | [小程序配置](docs/DEPLOY-MINIAPP.md) |
| 微信公众号网页签到 | 具备网页授权能力的公众号凭证 | [公众号配置](docs/API-CONFIG.md#wechat-official) |
| 钉钉签到 | 钉钉应用 Client ID / Client Secret | [钉钉配置](docs/API-CONFIG.md#dingtalk) |
| Telegram 签到 | Bot Token、机器人用户名与 Webhook | [Telegram 配置](docs/API-CONFIG.md#telegram) |

微信小程序与公众号是两种不同接入方式，凭证不能混用。抽奖、主题动画和回放本身不需要 OpenAI、Gemini 或 OpenRouter API。

## 📁 源码目录

```text
lucky-draw-studio/
├─ server/          # VPS / 本地 Node.js 版本，含 Docker 配置
├─ cloudflare/      # Worker 后端、Pages 前端与构建工具
├─ miniapp/         # 微信小程序，用开发者工具导入
├─ docs/            # 部署和平台 API 配置教程
└─ README.md        # 项目功能介绍
```

VPS 使用 Node.js + Express + SQLite；Cloudflare 使用 Worker、SQLite Durable Objects 与 KV。两种部署的数据独立，不会自动同步账号、活动或后台配置。
