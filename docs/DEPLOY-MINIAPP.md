# 📱 微信小程序部署、报名与发布

[← 返回功能介绍](../README.md) · [🔑 各平台 API](API-CONFIG.md) · [🖥️ VPS](DEPLOY-VPS.md) · [☁️ Pages](DEPLOY-PAGES.md)

小程序是观众手机端，网站是活动管理和抽奖后端。**必须先让网站正常运行，再接小程序。**仅把小程序源码导入工具，不代表报名接口已经可用。

## 🧰 1. 准备自己的账号

1. 在 [微信公众平台](https://mp.weixin.qq.com/) 注册或使用自己的小程序账号。
2. 按平台要求完成主体资料、类目、备案等准备；具体资格与权限以你的后台显示为准。
3. 在开发设置中找到小程序 **AppID**，获取或重置 **AppSecret**。
4. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

AppID 可以放在小程序项目配置里；**AppSecret 只放网站服务端，不能放小程序、公开仓库或前端 JS。**公众号的 AppID / AppSecret 不能用来代替小程序凭证。

## 📂 2. 导入项目

1. 打开微信开发者工具 → **导入项目**。
2. 目录选择仓库里的 **`miniapp`**，不是整个仓库。
3. 填写自己的 AppID，确认编译类型为小程序。
4. 点击导入，检查页面目录中有 `pages/checkin/checkin`。

`touristappid` 只是源码占位值，不能用于正式登录与发布。测试号和开发工具“不校验合法域名”选项也不能代替正式配置。

## 🌐 3. 修改后端地址

### 只部署一个站点：推荐直接连接自己的后端

最新版 `miniapp/app.js` 提供 `apiUrl(site, path)`，原配套环境通过网关转发到多站点。自己只部署一个网站时，可以把该方法改为：

```js
apiUrl(site, path) {
  return 'https://lucky.example.com' + path;
},
```

将域名换成自己的最终 HTTPS 网站。保留原有扫码解析和登录方法，不要把整个 `app.js` 换成这几行。

同时找到 `QR_HOSTS`，把自己的普通链接二维码域名加入白名单。例如自己只有一个 VPS 站点：

```js
const QR_HOSTS = new Map([
  ['lucky.example.com', 'legacy']
]);
```

若部署 Cloudflare 站点，对应使用 `'cf'`。`legacy` / `cn` / `cf` 是站点路由标识，不是 AppID。太阳码中的 `site` 与后端生成的值保持一致；`apiUrl` 单站直连时都应指向你自己的同一个后端。

另外检查 `utils-profile.js` 等文件中的默认 LOGO 地址，把仍指向演示站点的地址改成自己的 `/default-logo.jpg` 或本地素材。

### 已有多站网关：保留路由方式

保留 `apiUrl` 网关拼接逻辑，修改 `GATEWAY_URL` 与 `QR_HOSTS`，并在自己的网关反代中映射 `legacy` / `cn` / `cf` 到相应后端。

若源码包附带 `server/miniapp-gateway.inc.example`，它是原配套多站环境示例，不是通用即插即用配置。上游地址、容器名、Host 和 DNS resolver 都要按自己的网络修改。

只需要一个网站时不必额外搭网关，先采用上面的直连方式。

## 🔑 4. 网站后台配置微信凭证

1. 用站长账号打开自己网站的 `/settings/wechat`。
2. 活动域名填写自己的 HTTPS 根地址。
3. 填写**小程序** AppID、AppSecret，保存。
4. 若平台提示服务器出口 IP 白名单，按报错和账号要求填写真正的服务端出口 IP。

VPS 也可通过 `.env` 设置 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET`；Cloudflare 可通过 Worker Secrets 设置。同名环境变量优先于页面配置，改后台没生效时先检查是否保留了旧环境变量。

当前接入中的微信配置项会被小程序相关接口读取，不要把同一组配置同时填成另一套公众号凭证。

## ✅ 5. 设置小程序合法域名

微信公众平台 → 开发管理 / 开发设置 → 服务器域名：

- **request 合法域名**：填写小程序实际请求的 HTTPS 域名。
- 若用网关，填写网关域名；若直连，填写网站域名。
- 域名使用有效证书，按平台要求完成备案等检查，不带 `/api` 路径。
- 如当前代码使用了网络图片下载或文件上传，还需按实际调用配置对应的 downloadFile / uploadFile 合法域名。

开发工具里临时关闭域名检查，只能用于调试。正式版真机仍会校验，不能靠这个选项上线。

## 🔒 6. 用户隐私保护指引

在公众平台完善《用户隐私保护指引》，按实际使用声明：

- 用户选择的头像、昵称：活动报名、现场头像展示和中奖公示。
- 用户填写的留言：现场互动展示。
- 如用到选择图片、文件等能力，按实际调用补充相应信息类型。
- 联系方式、保存期限、变更告知方式等填写自己的实际情况。

不要勾选并未使用的手机号、定位、通讯录等信息。小程序报名页使用头像选择与昵称填写；当微信要求隐私授权时按平台流程展示，不绕过用户选择。

官方说明：[隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/) · [头像昵称填写能力](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/userProfile.html)

## 🧪 7. 体验版与正式版分别测试

| 版本 | 谁可以访问 | 适用场景 |
| --- | --- | --- |
| 开发版 | 配置好的开发人员 | 开发工具预览 |
| 体验版 | 后台添加的体验者 | 发布前测试 |
| 正式版 | 符合平台条件的普通用户 | 活动现场 |

最新版网站生成现场活动太阳码时使用正式版入口。**上传了体验版，不会自动更新正式版。**如果正式版仍旧，现场扫码仍会使用旧代码。

推荐流程：开发工具编译 → 上传体验版 → 添加测试者并真机验收 → 提交审核 → 审核通过后点击发布 → 用普通微信账号扫描新生成的活动码。

“不是当前小程序的体验者”通常说明扫到体验版码。核对二维码版本、AppID 与实际发布状态，不能只靠重新上传源码解决。

## 🧾 8. 真机验收清单

- [ ] 扫新活动码进入正确活动，名称和主题正确。
- [ ] 能选择头像、填写昵称，点击报名后大屏人数增加。
- [ ] 重复进入不重复增加名额。
- [ ] 快捷祝福 6 个，输入框每次点击清空，发送后重新预填随机留言。
- [ ] 留言间隔按站长配置生效，同一用户换活动可独立发送。
- [ ] 爱心、鲜花、火箭、跑车能在大屏显示，限额按活动独立计算。
- [ ] 开奖后结果可同步，已结束活动不能继续加入奖池。
- [ ] 正式版与后端都已更新，没有把 session_key 返回到客户端。

手机端问题先看开发工具请求日志中的接口、HTTP 状态和错误信息，再对照 [常见问题](FAQ.md)。不要把 AppSecret 或完整登录令牌贴到公开 Issue。
