# 🧰 常见问题与上线验收

[← 项目介绍](../README.md) · [VPS 教程](DEPLOY-VPS.md) · [Pages 教程](DEPLOY-PAGES.md) · [API 配置](API-CONFIG.md)

## 👑 默认账号和密码是什么？

没有通用默认账号密码。首次打开 `/setup`，填写自己的 SETUP_KEY 并创建站长；以后从 `/owner` 登录。VPS 的初始化密钥在自己的 `.env` 或本机生成文件中，Cloudflare 使用 Worker Secret。

## 🌐 网站 502 / 503 怎么办？

| 现象 | 检查顺序 |
| --- | --- |
| VPS 502 | `docker compose ps` → 容器日志 → 本机 `curl /healthz` → 反代上游地址和端口 |
| NPM 连不上应用 | NPM 在容器中时，127.0.0.1 指向它自己；检查共享网络和应用别名 |
| Pages 503 / API_BACKEND_NOT_CONFIGURED | Pages 的 API_BACKEND 服务绑定是否指向已部署 Worker，保存后是否重新部署 |
| 手机打不开 | 是否仍填 localhost / 内网地址，证书、DNS 与防火墙是否正确 |

## 🎨 主题只变底色，设置突然全展开？

先确认网站 HTML 与 JS 是同一版，刷新缓存后重试。新版主题会预加载图片并显示切换提示。

若旧奖品输入框重新出现、舞台设置没有折叠，或按钮大面积失效，打开浏览器开发者工具 Console 查看 JS 加载错误。最新版已修复普通脚本与模块导入混用导致初始化中断的问题；上传时应连同相应 HTML 和 JS 一起更新，而不是只覆盖一个文件。

## 🎵 音乐为什么没自动播放？

浏览器可能要求先点击页面才能发声。点击大屏控制按钮或音乐试听后再试，并检查静音、页面音量和活动音乐开关。

本场音乐只作用于对应活动；站长的各主题默认音乐是另一层设置。音频每首不超过 12 MB。上传后要保存，不能只选择文件就关闭弹窗。

## 📱 扫码提示不是体验者、活动无效？

- “不是体验者”：核对是否扫到体验版码，正式版是否已发布，AppID 是否一致。
- “未识别到有效活动”：检查新活动码、scene / path 解析、站点标识和后端地址。
- 上传体验版不会更新正式版；修改小程序源码后需重新上传并发布。
- 头像昵称不能承诺静默读取；使用用户主动选择、填写的资料报名。

完整步骤见 [小程序教程](DEPLOY-MINIAPP.md)。

## 🎬 回放数据在哪里？

数据在打开大屏的浏览器、对应网站域名的本地存储中。换电脑、换浏览器或换域名，不会自动带过去；清理网站数据会丢失本地回放。

从打开大屏开始计时，关闭后停止，再打开续接；最小化继续记活动数据。回放是舞台重绘与配置音乐，不包含麦克风、桌面窗口或未成功记录的历史现场内容。

导出是否比实时快取决于浏览器编码能力、分辨率、帧率和电脑性能。先尝试 1080p / 30 FPS；“正在合成 MP4”时仍在工作，不要马上关闭页面。

## 🗑️ 删除活动后录像还在吗？

新版删除活动时清理当前浏览器关联的录像与回放数据，打开活动管理页也会清理不再有效的历史记录。其他电脑离线保存的数据无法由当前浏览器远程直接删除。

网站运行数据、上传音乐和主题素材不是旧录像，不要为了腾空间把整个 data 或 public 文件夹删除。

## 🔄 升级后需要重新填 API 吗？

保留运行数据和存储绑定的正常升级通常不需要重新配置。Docker 保留命名卷和 `.env`；Cloudflare 保留 Worker、DO / KV 与 Secrets。源码包不应包含你生产环境的密钥和数据库。

## ✅ 正式活动前，完整走一次

- [ ] 站长和普通用户名账号均能按权限登录。
- [ ] 主办方、活动名称、参与方式和名单人数正确。
- [ ] 奖品图片按名次显示，修改 A 活动不会覆盖 B 活动。
- [ ] 候场 / 摇奖 / 颁奖音乐可试听，当前活动设置已保存。
- [ ] 主题切换加载完整，大屏全屏后头像与模块比例正常。
- [ ] 手动或自动开奖符合预期，已中奖者不再进入后续候选。
- [ ] 自己需要的平台已做真实扫码 / 评论导入测试。
- [ ] 结果图片、Excel、候场 / 摇奖 / 完整 MP4 均试导出过。
- [ ] 活动前已备份生产配置与数据。

发现问题时附上：使用版本、VPS 还是 Pages、浏览器、复现步骤和不含密钥的错误提示。不要公开真实参与者名单或登录凭证。
