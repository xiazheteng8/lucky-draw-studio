# 扫码平台配置

## 隐藏配置入口

在运行站点的域名后访问下列地址，登录管理员后填写配置。普通页面不展示这些入口；未配置的平台不显示为可选签到方式。

| 平台 | 地址 | 所需配置 |
| --- | --- | --- |
| 微信 | `/settings/wechat` | 公众号网页授权权限、App ID、App Secret、授权域名 |
| 钉钉 | `/settings/dingtalk` | 应用 Client ID、Client Secret、登录回调、个人信息读取权限与应用使用范围 |
| TG | `/settings/telegram` | BotFather 创建的 Bot Token、机器人用户名与公开 HTTPS 域名 |

微信回调为 `/api/wechat/callback`，钉钉回调为 `/api/signin/dingtalk/callback`。TG 保存后点击“启用接收”，注册 `/api/signin/telegram/webhook`；观众扫码打开机器人并点击开始签到，再通过机器人按钮返回互动页。

微信可上传平台提供的 MP_verify 域名校验文件。所有平台需按各自后台要求完成授权和回调配置。

## 环境变量

在 `.env` 配置以下变量，或使用隐藏入口保存配置。

| 变量 | 内容 |
| --- | --- |
| SIGNIN_BASE_URL | 手机可访问的 HTTPS 根域名 |
| WECHAT_APP_ID / WECHAT_APP_SECRET | 微信公众号凭证 |
| DINGTALK_CLIENT_ID / DINGTALK_CLIENT_SECRET | 钉钉应用凭证 |
| TELEGRAM_BOT_TOKEN / TELEGRAM_BOT_USERNAME | TG 机器人凭证和用户名 |
| TELEGRAM_WEBHOOK_SECRET | 可选的机器人回调校验密钥 |

环境变量优先于页面保存的配置。TG 使用环境变量时，仍需到隐藏入口启用接收。密钥字段不会回显，留空保存会保留已有密钥。
