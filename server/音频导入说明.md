# 背景音乐设置

部署包包含可直接播放的背景音乐。默认候场《喜洋洋》、摇奖《Go Time》、颁奖《Victory》。在音乐设置中试听、选择各阶段曲目并调整音量；曲目清单见《精选音乐曲库.md》。

可上传自己的 MP3、WAV、OGG、M4A、WebM，单首不超过12MB。较大的无损音乐可先转为 MP3 或 M4A，再上传使用。曲库中尚无音频的条目需上传绑定后才能选为背景音乐。

直播页需点击“开启音乐”后播放。视频导出可包含所选音乐；请保持导出页面前台运行。

本地/VPS 上传音频保存于 data 目录，Cloudflare 上传音频保存于 R2。更新部署时保留相应数据和存储绑定。
