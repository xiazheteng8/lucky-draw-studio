YouTube API 密钥：正在读取…

API 是可选项。未填写时尝试读取公开评论；配置 YouTube 官方 API 可提高读取稳定性，并补全视频、账号和头像信息。API 无法读取已删除、私密或关闭的评论。

为什么配置 API？如何获取？
  1. 打开 Google Cloud 控制台，创建或选择项目。
  2. 在“API 和服务 → 库”启用 YouTube Data API v3。
  3. 在“凭据 → 创建凭据 → API 密钥”生成密钥，并将 API 限制为 YouTube Data API v3。
  4. 将密钥粘贴到这里并保存。密钥保存在服务端，请勿公开。
