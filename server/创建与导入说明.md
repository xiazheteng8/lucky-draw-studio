# 创建活动与导入名单

## 从视频或文章导入

“从视频导入”：填写完整视频链接。YouTube 配置 API 后优先使用官方接口；没有 API 时尝试读取公开评论。其他平台请自行尝试是否支持，读取受平台权限、网络和评论开放状态影响。

“从 blog 导入”：从文章链接抓取评论（如果支持）。文章平台限制评论读取时，可自行导出评论名单后上传；文章正文不能替代评论名单。

API 配置按钮内提供配置用途与操作方法。没有 API 仍可导入名单并抽奖。

## 自定义名单文件夹

下载导入模板 ZIP，解压并编辑名单表格，将头像与表格放入同一文件夹，再把整个文件夹拖到页面。文件夹只保留一份 XLSX、CSV 或 TSV 名单。

推荐表头：`编号、姓名、头像文件`。头像列填写含扩展名的文件名，例如 `001.jpg`；没有头像可留空。相同编号会去重。评论名单另需 `账号、评论`，账号填写真实 `@账号`。

`获奖名称` 是可选列，按高到低填写第一名、第二名等名称，也可填写特等奖、一等奖等。它定义奖项名称，不指定某行人员中奖；名单中无需奖品列。

头像支持 PNG/JPG/WebP，单张不超过300KB，总量不超过10MB；名单文件不超过8MB、最多10000行，较大名单分批导入。

## 创建与开奖

填写活动名称、中奖人数、参与条件，选择抽奖模式、动画、奖章与获奖名称，创建后检查参与名单。自定义名单不需要视频链接或 API。

打开直播大屏后开始抽奖。各名次倒序揭晓；手动模式每次抽中一位后，点击“立即抽取下一位”继续。开奖后名单不可修改。

评论类画面使用 `@账号 + 评论`，长评论可省略显示；中奖表格保留完整正文和导入字段。
