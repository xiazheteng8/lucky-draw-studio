# Cloudflare、GitHub 与扫码配置

## Cloudflare 部署

使用 Cloudflare-GitHub 包，安装 Node.js 22 或更高版本，双击“部署到Cloudflare.cmd”，按提示安装依赖、登录 Cloudflare、创建或绑定存储，首次部署需设置站长账号密码。也可运行：

```sh
npm ci
npm run deploy:cloudflare
```

账号需要 Workers、Durable Objects、KV 和 R2 对应资源权限；先在账号内启用 R2。创建页公开，实际操作需登录。

部署完成后访问域名的 `/admin`。大屏从活动卡片打开，使用静态入口 `/live.html?id=活动编号&token=大屏令牌`。页面、开奖和活动数据均由同一 Cloudflare 部署提供，不需要连接本地电脑或 VPS。

`wrangler.jsonc` 声明 `REGISTRY`、`ROOMS`、`CONFIG_KV`、`MEDIA` 和 `ASSETS`。首次部署按提示创建资源；已有 KV 空间可在 `kv_namespaces` 中填写对应 `id`。`CONFIG_KV` 必须是 KV 空间绑定，不能用普通字符串变量替代。

活动与开奖进度保存于 Durable Objects，上传音乐保存于 R2，扫码配置使用 KV 并由 Durable Objects 保持当前状态。后续部署保持 Worker 名、`STUDIO_ID`、空间绑定及迁移记录，避免切换到新的活动数据空间。

## GitHub 部署

将 Cloudflare-GitHub 包内容上传仓库，不上传 `.dev.vars`、密钥或依赖目录。在仓库 Secrets 配置：

- `CLOUDFLARE_API_TOKEN`：具备相应部署和存储权限的令牌。
- `CLOUDFLARE_ACCOUNT_ID`：Cloudflare 账号 ID。
- `ADMIN_PASSWORD`：管理员密码。

运行“Deploy standalone Cloudflare”工作流。平台凭证可在 Cloudflare 部署设置中配置，也可部署后访问下方隐藏入口填写。

GitHub Pages 作为活动入口使用，完整服务由 Cloudflare 运行。先部署 Cloudflare，再在仓库 Variables 添加 `PUBLIC_APP_URL`，填写 HTTPS 根域名；运行“GitHub Pages 活动入口”工作流，Pages 来源选择 GitHub Actions。访问 Pages 后会自动进入 Cloudflare 活动站点。平台密钥和 KV 配置留在 Cloudflare。

## 隐藏配置入口

在运行站点的域名后访问下列地址，登录管理员后填写配置。普通页面不展示这些入口；未配置的平台不显示为可选签到方式。

| 平台 | 地址 | 所需配置 |
| --- | --- | --- |
| 微信 | `/settings/wechat` | 公众号网页授权权限、App ID、App Secret、授权域名 |
| 钉钉 | `/settings/dingtalk` | 应用 Client ID、Client Secret、登录回调、个人信息读取权限与应用使用范围 |
| TG | `/settings/telegram` | BotFather 创建的 Bot Token、机器人用户名与公开 HTTPS 域名 |

微信回调为 `/api/wechat/callback`，钉钉回调为 `/api/signin/dingtalk/callback`。TG 保存后点击“启用接收”，注册 `/api/signin/telegram/webhook`；观众扫码打开机器人并点击开始签到，再通过机器人按钮返回互动页。

微信可上传平台提供的 MP_verify 域名校验文件。所有平台需按各自后台要求完成授权和回调配置。

## 环境变量

本地/VPS 在 `.env` 配置；Cloudflare 在部署设置配置，敏感值使用 Secret。

| 变量 | 内容 |
| --- | --- |
| SIGNIN_BASE_URL | 手机可访问的 HTTPS 根域名 |
| WECHAT_APP_ID / WECHAT_APP_SECRET | 微信公众号凭证 |
| DINGTALK_CLIENT_ID / DINGTALK_CLIENT_SECRET | 钉钉应用凭证 |
| TELEGRAM_BOT_TOKEN / TELEGRAM_BOT_USERNAME | TG 机器人凭证和用户名 |
| TELEGRAM_WEBHOOK_SECRET | 可选的机器人回调校验密钥 |

环境变量优先于页面保存的配置。TG 使用环境变量时，仍需到隐藏入口启用接收。密钥字段不会回显，留空保存会保留已有密钥。

## 更新与备份

重新部署前保留原有资源名称、绑定和管理员密钥，不要删除存储资源。重要活动请先导出中奖表格，并保存原始名单与上传音乐。不同运行环境的数据不会自动迁移。


当前版本采用多用户权限。创建表单公开，实际创建与管理需登录；首次通过 /setup 设置站长，后台 /owner。完整现场录像需在同一浏览器内打开大屏录制并导出，结束后场前请保持大屏打开。
