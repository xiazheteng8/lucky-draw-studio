# 账号与站长后台使用说明

公开创建页为 `/`；登录/注册入口为 `/account`（兼容 `/login`）；站长后台为 `/owner`；首次初始化为 `/setup`。

首次启动必须完成站长账号和密码设置。初始化还需要一次性 setupKey，防止公网访客抢先成为站长。本地/VPS 从服务器启动日志或私有数据目录的 `owner-setup-key` 读取；Cloudflare 部署前通过服务端 Secret `SETUP_KEY` 设置，不能写入前端或压缩包。初始化成功后入口关闭，原有活动归站长。

所有人可以打开创建页、查看和填写创建表单。实际创建活动、开奖、导入/修改名单，以及查看自己的活动详情都需要登录。用户之间互相隔离；站长可管理全部活动。活动公开大屏、扫码互动和公开结果仍按活动分享入口访问。

用户名密码直接注册属于未验证账号。必须同意临时账号规则：只能创建并安排在未来24小时内开奖的活动；未开奖活动到期自动清理；已开奖活动在揭晓结束后24小时删除服务器数据。清理包括评论、中奖名单和互动数据。不要把临时账号当成长期档案。

站长在 `/owner` 控制用户名密码、邮箱、手机号、微信、钉钉、Telegram 登录/注册方式。关闭或配置不完整的外部方式不展示为可用入口。站长密码入口应始终可用，避免自己被锁在后台外。

邮箱和手机验证码需要配置真实发送服务，HTTP POST 接收验证码任务并返回 JSON `{ "success": true }`，才能视为发送成功。服务凭证只保存在服务器，不在管理读取接口回显。验证码会限流、过期且一次使用。登录后可按站长启用的方式绑定邮箱/手机号。

微信登录需要开放平台网站应用，钉钉需要配置应用登录权限，Telegram 需要机器人及登录域名。站点账号登录凭证与“活动观众签到”凭证相互独立。填写凭证并不等于真实授权验收成功，应使用实际账号扫码检查。

升级部署保留现有数据库、活动、媒体和平台配置；务必备份后更新。多用户版上线后原来的免登录管理入口将关闭。不要在公开聊天发送站长密码，请在自己的浏览器内完成初始化。
