# 扫码互动与活动标志

创建活动时开启“等待开奖时开启扫码互动”，大屏等待页面显示二维码。普通活动的观众可扫码填写昵称、发送120字以内留言和点击爱心，互动不增加抽奖资格。

选择“微信/钉钉/TG扫码”模式时，先配置对应平台，观众完成签到后获得资格。未配置的平台会隐藏；入口和所需凭证见《云端大屏与扫码配置.md》。活动开奖后停止接收互动。

留言缓慢由下往上播放，接近顶部淡出；爱心独立上浮。大屏左上方使用“瞎折腾摇奖吧”，主画面和浏览器标题显示活动名称。

本地普通互动要求手机与电脑连接同一网络。自动识别地址不正确时，在“手机访问地址”填写电脑局域网地址，例如 `http://192.168.1.8:3000`。手机不能使用电脑的 localhost 地址；网络和防火墙需允许访问应用端口。

VPS 和 Cloudflare 使用手机可访问的域名。微信、钉钉授权和 TG 机器人回调使用公开 HTTPS 地址，纯局域网地址不能替代平台要求的回调域名。

默认标志为瞎折腾头像，可上传500KB以内的 PNG/JPG/WebP，建议使用正方形图片，也可恢复默认。已有待开奖活动修改标志、手机地址或互动开关后，点击“应用当前舞台设置”，再刷新大屏。

观众离开后可重新扫码，或在手机页使用“保存活动入口”。网站无法强制微信显示原生悬浮窗口，建议把活动链接保存在文件传输助手等便于返回的位置。
